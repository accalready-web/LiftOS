# LiftOS — Project Rules

## Context & Workflow Rules (Token-Saving)
1. **Before starting any task:** Read `STATUS.md` first to understand the current phase and next action. Only read `docs/` files relevant to the current step.
2. **Work in phases:** Focus only on the requested step in the current chat. Do not jump ahead to unrelated phases.
3. **Before finishing a chat / phase:** Always update `STATUS.md` with:
   - What was completed
   - Key decisions or files changed
   - Exact next step for the next chat
4. **Language:** Communicate with the user in Thai unless asked otherwise. Keep code, identifiers, and technical terms in English.
